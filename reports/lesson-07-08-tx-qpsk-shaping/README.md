# Занятия 7–8. Передатчик: биты → QPSK → upsampling → свёртка → TX (20.10, 27.10)

**Даты:** 20.10 (занятие 7), 27.10 (занятие 8)
**Стенд:** 2 × ADALM-Pluto, Fs 1 МГц, TX 800 МГц / RX 840 МГц (и наоборот), TX gain 71 дБ, RX gain 60 дБ, BW 200 кГц
**Код занятия:** [`scripts/lesson08/`](../../scripts/lesson08/) (снапшот кода урока 8), [`src/main.c`](../../src/main.c) (файловый TX)
**ДЗ от 21.10 (из чата):** 1) генератор битов, 2) модуляция BPSK/QPSK комплексными значениями, 3) нули между символами (upsampling), 4) свёртка для прямоугольных импульсов

---

## 1. Задача

Перейти от тона/константы (занятие 6) к цифровой передаче: имя `TIMUR` → ASCII-биты →
Gray-QPSK → upsampling ×4 → свёртка с прямоугольным импульсом длиной 4 → CS16-файл,
который передатчик крутит в эфир. Приёмник пишет `.pcm`, обработка офлайн в Python.

## 2. Ход работы

1. `gen_tx_name.py`: `name_to_bits` (8 бит на символ, старший бит первым),
   `modulate_qpsk` (Gray: 00→++ , 01→−+ , 11→−− , 10→+− , амплитуда 1/√2 по оси),
   `upsample` (импульс каждые SPS=4), `pulse_shaping_rect` (`np.convolve` с `ones(4)`),
   `save_cs16` (масштаб 15000, клип по ±32767).
2. `main.c` переделан на передачу из файла: весь `tx_name.pcm` читается в память,
   буфер потока заполняется файлом по кругу.
3. Приём и графики: `plot_rx_time.py` (I/Q/|z| окном), `plot_constellation.py`
   (созвездие по «активным» отсчётам), `plot2.py` («созвездия по цифрам»), `magnitude.py`
   (|свёртки|).

Параметры кадра урока 8: текста 5 символов = 40 бит = 20 QPSK-символов; после upsampling
80 отсчётов; после свёртки 83 отсчёта (83 мкс при Fs 1 МГц).

## 3. Что не получилось

Главное: **созвездие не сошлось**. Диагноз по четырём графикам (все лежат в `../assets/`):

Плюс системные ошибки кадра урока 8:

- **Нет границы кадра и метки фазы.** Файл из 83 отсчётов циклически повторялся внутри
  буфера 4096: 83 не делит 4096, фаза паттерна прыгала на каждом обороте, приёмник не имел
  ни точки отсчёта символов, ни начала пакета.
- **Полоса не согласована со скоростью.** BW 200 кГц при символьной скорости
  Fs/SPS = 250 ксим/с: первый нуль спектра прямоугольного импульса на 250 кГц — аналоговый
  фильтр режет спектр и скругляет импульсы (межсимвольная помеха).
- **Утечка несущей и DC-биения** не учитывались: постоянная составляющая приёмного сигнала
  мешала пороговой обработке огибающей.

## 4. Решения (переходят в занятие 9)

1. Кадр = `[тишина 2048][преамбула 16 символов][данные]`, свёртка по **общей**
   последовательности символов (при раздельной свёртке преамбулы и данных между ними
   возникал лишний хвост `sps-1` отсчётов и сетка символов съезжала на 1 — поймано отладкой
   02.11 по «вееру» ±19° на созвездии).
2. TX пишет поток непрерывно; паузы существуют только внутри кадра (тишина).
3. Офлайн-приёмник [`scripts/rx_offline.py`](../../scripts/rx_offline.py): детектор
   всплесков, поиск расстройки, корреляция с преамбулой, согласованный фильтр, выбор
   символьных отсчётов, решения, текст. Цепочка обработки и результаты прогонов — в
   [scripts/README.md](../../scripts/README.md), история отладки — в CHANGELOG (неделя 9).

## 5. Результат

- Цепочка TX работает end-to-end: текст → файл → эфир → запись (графики выше).
- Получен отрицательный результат с полным диагнозом: без синхронизации созвездие
   принципиально не сходится (кольцо), «красивые» графики урока 8 оказались артефактами
   обработки (таблица выше).
- Код урока 8 сохранён как есть в [`scripts/lesson08/`](../../scripts/lesson08/) — это
   история, правки в него не вносятся.

## 6. Вывод

Цифровая передача начинается не с модуляции, а с договорённости о кадре: граница,
маркер для синхронизации и согласованная полоса. Модулятор без этих трёх вещей
даёт на приёмнике кольцо шума, какие бы gain ни крутить.
