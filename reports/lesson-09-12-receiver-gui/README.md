# Занятия 9–12. Приёмник, синхронизация, окно (03.11, 10.11, 17.11, 24.11)

**Стенд:** 2 × ADALM-Pluto, частота 1 МГц, 10 отсчётов на символ, TX 800 МГц / RX 840 МГц. Проверка без железа — режим `pluto_gui --sim`.
**Код:** [`src/backend.cpp`](../../src/backend.cpp), [`src/timing.h`](../../src/timing.h), [`src/gui.cpp`](../../src/gui.cpp), [`tests/test_dsp.cpp`](../../tests/test_dsp.cpp)

---

## 1. Задача

Собрать приёмник, который читает слово `TIMUR` из эфира, и окно, где видно каждый этап:
сигнал, символы, синхронизацию, водопад. На занятии 12 добавить маркер в начало пакета.

## 2. Ход работы

1. Приёмник на C++: убрать постоянную составляющую, найти пакет по огибающей, оценить сдвиг частоты, выбрать моменты отсчёта, подстроить фазу, декодировать.
2. Три детектора ошибки тактовой синхронизации — ZC, Гарднер, Мюллер и Мюллер — и режим «Энергия». Формулы из гл. 6.4.
3. Окно на ImGui и ImPlot: пять вкладок, настройки справа.
4. Маркер. В пакет добавлен код Баркера-13 (13 символов +1/−1, у него боковые пики корреляции не больше 1 из 13). Приёмник считает корреляцию с эталоном, пик выше порога 0,7 — начало пакета. Фаза пика даёт фазу несущей.
5. Тесты на синтетическом сигнале (11 штук) — чтобы проверять каждую правку одной командой.

## 3. Что не получилось

| Симптом | Причина | Решение |
|---|---|---|
| Слово не читается, созвездие — кольцо | В петлю Костаса (подстройка фазы) символы шли без нормировки, а её ошибка растёт с амплитудой. Грубая частота при этом была верной: 3174 Гц при заданных 3155 | Символы нормируются по мощности перед Костасом |
| Петля пропускает символы при быстрой настройке | Условие считало штатный интервал в 9 отсчётов лишним | Порог интервала `N − 1` вместо `N` |
| Ложная ошибка на первом символе пакета | Нет предыдущего символа для сравнения | Первый символ только запоминается |
| Окно падало на вкладке «Синхронизация» | Ось X графика ошибки передавалась как `nullptr` | Ось строится по номерам символов |
| Панель настроек была под основным окном | Флаг окна уводил её на задний план | Флаг убран |
| Слабый сигнал не находится | Порог поиска пакета 30 отсчётов АЦП | Так задумано, чтобы не принимать шум за пакет |

## 4. Результат (симуляция)

Сдвиг частоты 3155 Гц, постоянная составляющая, шум. Пачка из 5 пакетов, во всех режимах 5 из 5 найдено, слово `TIMUR`, совпадение 100 %.

| Режим | EVM (расстояние до идеальной точки) |
|---|---|
| Энергия | 12–14 % |
| ZC | 4,4 % |
| Гарднер | 15–18 % |
| Мюллер и Мюллер | 4,6 % |

Тесты: 11 из 11. Для проверки самих тестов по очереди ломал код (убирал нормировку, возвращал условие `N`, убирал запоминание первого символа) — каждый раз краснел именно нужный тест.
