## Цепочка обработки в `rx_offline.py`

Порядок шагов важен, перестановка ломает всё ниже по цепочке:

1. **Детектор всплесков.** Огибающая `|z|` сглаживается скользящим средним (256 отсчётов),
   порог 0.4 от перцентиля 99.5. Без сглаживания порог по сырым `|z|` рвёт кадр дырками
   на шумных записях (SNR ~10 дБ), и преамбула теряется.
2. **Грубый поиск расстройки Δf.** Перебор гипотез ±16 кГц с шагом 400 Гц, затем ±400 Гц
   с шагом 50 Гц; метрика — сумма четырёх наибольших модулей корреляции с преамбулой.
   Диапазон ±16 кГц — порядок увода независимых гетеродинов двух плат на 800 МГц.
3. **Уточнение по дрейфу между кадрами.** Фаза корреляционных пиков преамбулы соседних
   кадров дрейфует на `2π·δ·T/Fs` (T — период кадра, известен точно); оценка по медиане
   пар, принимается только если метрика корреляции не ухудшилась.
4. **Согласованный фильтр.** Тот же прямоугольник длиной SPS, что на TX
   (`matched_filter_rect`, mode='full').
5. **Символьная синхронизация и фаза.** Корреляция с преамбулой: пик даёт начало кадра
   с точностью до отсчёта, угол пика — полную фазу кадра. Неоднозначности π/2 нет,
   потому что маркер несимметричный (метод четвёртой степени оставил бы её).
6. **Выбор символьных отсчётов.** После согласованного фильтра отклик на прямоугольный
   импульс — треугольник, единственная оптимальная точка символа j:
   `n = s0 + j·SPS + SPS − 1` (окно фильтра ровно накрывает плато).
   Визуализация: [`../reports/assets/rx-offline-magnitude-symbol-points.png`](../reports/assets/rx-offline-magnitude-symbol-points.png).
7. **Доводка фазы внутри кадра (decision-directed).** По решениям первой проходки
   считается остаточная фаза `angle(s·conj(d))`; линейная аппроксимация по времени даёт
   наклон (уточнение Δf до единиц Гц) и смещение; вторая проходка снимает символы
   с скорректированной фазой.
8. Решения по квадрантам (Gray), сборка байтов, голосование текста по кадрам.

самотест: [`../reports/assets/rx-offline-constellation-selftest.png`](../reports/assets/rx-offline-constellation-selftest.png).

## Проверки

```
python3 scripts/rx_offline.py --selftest
```

Самотест строит синтетический канал (Δf 1700 Гц, задержка 1234 отсчёта, фаза 0.7 рад,
шум, три кадра подряд) и декодирует его: ошибка оценки Δf единицы Гц, 3/3 кадра.
Прогон по сетке 4 расстройки (до ±9 кГц) × 2 задержки × SNR 10–25 дБ: 24/24 кадра.
История отладки цепочки — в [CHANGELOG.md](../CHANGELOG.md), неделя 9.

Записи занятия 8 этим приёмником не декодируются: в старом кадре не было преамбулы
и границы. Для проверки на железе нужна запись новым кадром.
